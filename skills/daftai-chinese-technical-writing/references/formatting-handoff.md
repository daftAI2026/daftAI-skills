# 格式联动契约

## 选择与解析

1. 优先找当前项目 `skills/daftai-chinese-copywriting/`。
2. 没有项目版本时，按宿主可用 Skill 清单定位安装版本。
3. 读取选中版本的 `SKILL.md`，记绝对路径为 `FORMAT_SKILL_DIR`。
4. 存在多个同优先级版本且无法判断时，询问用户。

不硬编码维护者的本机路径。
独立安装写作 Skill 不保证格式 Skill 也已安装。

## 模式边界

| 当前请求 | 委派模式 | 配置与写入 |
| --- | --- | --- |
| 检查格式、看看问题 | `review` | 无需偏好文件；不写修正副本 |
| 明确要求修正格式 | 按目标 Skill 选择 `stable` 或 `quick` | 遵守其首次设置与副本规则 |
| 只要求改写文案 | 不强制调用 CLI | 先完成语义任务 |

调用方要求对话报告时，消费 CLI 标准输出。
不要默认在原文目录创建审阅报告。
不为避开配置要求，把检查改成修正。
不代用户回答首次设置，不静默创建偏好文件。
格式 Skill 优先读取 EXTEND.json，兼容旧 EXTEND.md。
同层级 JSON 优先；项目层级高于用户层级。
新设置保存为 JSON，不因读取旧文件自动迁移。

## 执行契约

执行前检测 Bun 和 autocorrect。
工具缺失时不调用会自动安装依赖的 CLI。
可以继续人工核对，但必须注明未运行自动检查。
目标 Skill 未安装时，同样说明缺少委派能力。

命令工作目录设置为 `FORMAT_SKILL_DIR`。
文件参数使用绝对路径；支持的文件类型是 Markdown/TXT。
本 Skill 没有脚本目录，下列脚本属于格式 Skill。

```bash
bun "${FORMAT_SKILL_DIR}/scripts/main.ts" review "/absolute/path/to/draft.md"
```

对话短文本可以作为一个完整参数传入。
避免把不可信文本拼接进 shell 命令。
代码资源先提取文案，不把 JSON、YAML 或源码伪装成 TXT 输入。

CLI 的项目偏好相对于执行 cwd，不是输入文件目录。
修正前若偏好路径不匹配，报告并暂停自动修正。
不要虚构 `--cwd` 参数或向安装目录复制配置。

旧安装版本若在 `review` 拒绝缺少配置，报告版本行为不兼容。
若旧版本只支持 Markdown，报告格式差异，不把 JSON 文件改名伪装。
不要用 `init` 绕过只读边界，也不要修改用户安装的 Skill。
只有明确的临时故障才重试一次；配置拒绝不重复运行。

## 合并结果

- autocorrect 负责机械检查，不证明语义正确。
- AI 语境核对遵循格式 Skill 的规则参考，不复制一套检测器。
- 区分工具发现和人工发现。工具失败时不报告“检查通过”。
- 修正后核对命令、代码、链接目标、公式和占位符保持原样。
- 界面文案核对资源键、状态和动作没有改变。
- 用户显式指定的合法风格高于两份指南的默认风格。

阮一峰原指南允许中文与数字之间统一采用有空格或无空格。
未指定时，采用格式 Skill 的空格风格。
指定无空格时，把自动检查的冲突项解释为风格差异。
不要盲目应用工具改写，也不要把差异报告成语义错误。
