# 真实修改回环

本结构沿用 `daftai-writer` 的证据回环。
本 Skill 提炼工具型写作规则，不学习个人文章声线。

## 1. 确认维护范围

只有用户要求维护 Skill，才执行后续写入。
普通改稿不是修改 Skill 的授权。
不要默认保存用户材料、原稿或私人路径。

## 2. 比较完整语境

使用真实 AI 稿作为 `before`，用户改稿作为 `after`。
比较完整段落或组件，不只比较孤立的词。
区分事实纠错、范围变化、结构调整和表达偏好。

按以下类别归纳：

- 信息前置与步骤顺序。
- 长句拆分与歧义消除。
- 术语统一与字面量保护。
- 产品断言收缩与限制恢复。
- 界面状态、动作与恢复说明。
- 机械排版；这类改动转交格式 Skill，不重复立规则。

## 3. 区分证据等级

原指南规范保持原文来源。
产品与界面扩展保持扩展标记。
跨任务重复出现的表达改动，才是稳定规则候选。
用户明确要求的偏好可直接记录，但要写明适用范围。
一次出现或依赖特定题材的观察，留在 `style-evidence.md`。
事实纠错不能自动升级为所有任务的风格禁令。

## 4. 修改最小规则

把稳定观察写成具体修改动作。
合并同义规则，删除已经被覆盖的条目。
真实 diff 示例可以裁短，不能编造更漂亮的“真实样本”。
新增原创演示时，明确标为演示。
不要用演示反过来证明规则来自用户编辑。

## 5. 回归检查

按 `acceptance-cases.md` 检查三种场景。
确认新规则没有改变事实或破坏字面量。
格式委派仍使用独立入口和正确模式。
无重复证据的规则，不因维护便利提升等级。
