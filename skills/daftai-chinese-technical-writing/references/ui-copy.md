# 界面文案扩展

本文件是原创场景扩展，不是阮一峰原文。
示例展示表达方式，不代表真实状态或功能。

## 按组件选择信息

| 组件 | 文案任务 | 原创示例 |
| --- | --- | --- |
| 按钮 | 动作明确；需要时加对象 | 保存设置、重新上传 |
| 字段标签 | 命名输入对象 | 工作邮箱 |
| 辅助说明 | 给出已知要求或用途 | 用于接收任务通知 |
| 输入错误 | 指出错误对象与修改方法 | 输入完整的邮箱地址 |
| 空状态 | 区分从未创建与无搜索结果 | 暂无项目；未找到匹配项目 |
| 进行状态 | 描述当前动作 | 正在上传文件 |
| 成功提示 | 只确认已完成的事 | 设置已保存 |
| 失败提示 | 说明失败对象和真实可行的下一步 | 上传失败，请重试 |
| 危险确认 | 说明对象、影响和可用选择 | 删除项目；取消 |

例中的动作只有在真实流程支持时才能使用。
未知失败原因时，不写“网络异常”或“权限不足”。
不知道是否保留草稿时，不写“内容已自动保存”。
不知道是否可恢复时，先确认，不承诺恢复或永久删除。

## 状态与动作

- 用相同名称指代相同对象和动作。
- 把按钮放回弹窗或页面语境，核对动作是否一致。
- 明确区分“取消订阅”和“删除账号”。
- 对危险操作，不用“确定”掩盖具体动作。
- 保留禁止与权限信息，不为肯定句改写错误状态。
- 删除“抱歉给您带来不便”等空话，不责备用户。
- 没有恢复动作时，写清已知状态，不发明“联系支持”入口。

## 字面量与长度

保留资源键、代码、路径、URL、转义和插值语法。
逐字保留 `{count}`、`{{name}}`、`%s`、`${value}` 等占位符。
不要翻译变量名或改变参数顺序。
ICU MessageFormat 的分支和嵌套语法保持原样。
需要调整这些语法时，按开发任务单独验证。

对 JSON、YAML 和源码，不把整份文件交给排版 CLI。
按键名提取目标文案，给出逐项建议或精确字符串补丁。
没有获得文件修改要求时，仅在对话中给结果。

用户给出长度上限时，实际计数并注明计数口径。
没有指定时，按 Unicode 码点计算，包含标点和空格。
含占位符时分别说明模板长度与未知的运行时长度。
不能把模板字符数当成最终显示宽度。

## 交付

单条文案直接给结果。
批量文案保留用户给出的资源键或位置。
需要表格时使用“键或位置｜建议文案｜必要说明”。
说明只列事实缺口、状态风险或超长原因。
不要默认输出口号、三个版本或逐条夸奖。
