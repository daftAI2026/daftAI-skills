# STE 启发的受控中文技术写作

本文件是中文适配，不是 ASD-STE100 译本。
目标是消除会改变读者判断或操作的歧义。
方法出处与许可见[来源说明](source-guide.md)。
本方法不构成 STE 合规检查、认证或安全验证。

## 选择适用范围

| 场景 | 应用方式 |
| --- | --- |
| 操作手册、安装部署、排查、Runbook、安全说明、多步骤 API | 应用本文件的操作方法；只写有依据的条件、动作和结果 |
| API 概念、工具描述、Agent 状态、FAQ、更新日志与功能说明 | 选择术语、指代、逻辑和事实保真检查；不强制改成步骤 |
| 品牌文案、作者文章、正式引用、短按钮和导航 | 不机械套操作模板；仍保留事实、限制和字面量 |

按段落判断，不按文件名判断。
README 内的操作段落和产品介绍采用不同写法。
清晰文本允许不改。长句和近义词本身不是错误。
工具描述与 Agent 指令仍受原任务模式约束。
不能因面向 Agent 就把建议升级成命令。

## 六项方法

### 1. 对齐概念，不机械统一词形

同一产品概念在当前文档中使用同一名称。
不同概念保留区别，不建全局一词一义词典。
取消、超时和失败不是同一状态。
检查地址与确认送达不是同一动作。
界面标签、命令、标识符和占位符保持原样。
陌生术语只在读者需要且含义有依据时解释。

### 2. 明确执行者，不补造主语

区分读者动作与系统自动行为。
不要把保存后的系统行为写成人工步骤。
说明性内容中，执行者未知或无关时可保留被动句。
执行者影响责任或安全且来源未明确时，标明缺口。
代词存在多个解释时，询问或列出歧义，不猜执行者。

### 3. 前置条件，保留逻辑范围

先判断条件约束哪个动作，以及是否要求动作完成。
区分必要条件、充分条件与可选前提。
调整顺序时，保留“全部／任一”“且／或”、否定和例外。
保留数值、单位、上下界及是否包含边界。

例：仅在校验通过时才允许重试。
校验通过不表示必须重试；未通过时不得重试。
不能改成“校验通过后，重试”。

上传完成不能缩成上传开始。
自动恢复未成功不能缩成自动恢复未启用。
允许自动解决不表示已经成功解决。
原文人工回退覆盖“获准但失败”时，保留该情境。
原文未给出该回退时，不自行增加。
条件前置不能扩大许可，也不能增加义务。

### 4. 按真实顺序拆分动作

一个步骤围绕一个主要动作。
有真实先后关系时用编号；并列选项不能改成连续步骤。
同时完成或不可分的动作保留在同一步。
测量动作及其结果限值也可以写在同一步。
一步可含多句，不按动词数量机械拆步。

操作指令使用明确动词，但不删除原有义务强度。
说明能力时保留“可以”；表达建议时保留建议含义。
要求、许可、建议、计划和确定程度不能互换。
不要把功能说明改成操作命令。
保留曾经、已、正在、尚未和仍然的时间范围。
任务完成不表示产物现在仍可下载。

### 5. 分开步骤、说明和警告

步骤交代要做什么，说明交代背景或系统行为。
必要动作、要求和限值不能只藏在备注中。
允许调整结构时，把它们移到对应步骤。
只读审阅时指出问题，不直接重排原稿。

把已知警告放在会产生该风险的动作之前。
说明已知的风险条件、影响对象和后果。
风险标识沿用领域与项目规范，不照搬航空分类。
固定或已批准的警告原文不改，建议单独列出。
缺少安全事实时标明缺口，不编造阈值或保障措施。

### 6. 给出已知结果和失败分支

资料足够时，交代前提、动作、预期结果与停止条件。
恢复方式有依据时才写，不补造成功标志或恢复承诺。
资料不足时，标明缺口，不宣称草稿已安全可执行。

排查先区分现象、证据、推测、检查动作和验证结果。
优先安排低风险、可逆且能提供证据的检查。
保留推测语气，不能从超时推断凭证失效。
仅改措辞时，不擅自增加重启、删除、备份或回滚步骤。
合理的检查动作也是新增方案，不能伪装成改写。
缺少实质信息时指出缺口，不补能力、频率或实现机制。
撰写 Runbook 不授权执行 Runbook。
编辑 Agent 指令不授权重设权限、工具保证或工作流。

## 按读者决策复核

对照改稿与原稿，逐项核对：

- 谁对哪个对象采取动作。
- 什么条件允许或要求该动作。
- 动作必须开始还是必须完成。
- 是必选步骤、可选能力还是建议。
- 过去、当前或未来的状态范围是否保持不变。
- 已知结果、限制、例外和失败分支是否相同。

用具体情境检查，不能只检查关键词。
例如分别检查校验失败、通过但无需重试的情境。
自动恢复则检查关闭、启用但失败、启用且成功的情境。
改稿扩大动作许可、增加义务或系统承诺时，撤销该变化。

歧义未解决时，审阅列出竞争解释。
改写先集中追问，或保留并标明受影响的原句。
不要选择更容易写顺的解释来替代事实。

## 避免机械套用

不把英文受控词典、词性、时态或短语动词限制用于中文。
不把英文词数、段落句数换算成中文硬上限。
不为主动句虚构执行者，也不为短句删掉条件。
不新增术语配额、统一引号风格或排版检查器。
机械格式仍委派给现有格式 Skill。
自动格式检查不证明语义保真或符合标准。
